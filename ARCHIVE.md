# Archived Python Potatoplayer

This branch preserves the original Python Potatoplayer implementation that
preceded the Super/Ultra Electron versions.

Included:

- `Potatoplayer.py` — Tkinter player
- `Potatoplayer_qt.py` — Qt player
- `core/` — shared backend and theme modules
- `README.md`, `CHANGELOG.md`, `SUMMARY.md`, `updatelog`
- launcher scripts, requirements, icons and the cover test

Intentionally excluded from this archive:

- `logs/` and local screenshots
- `sample/` audio (including copyrighted test tracks)
- `source/` library metadata, ratings and blocks
- `__pycache__/`, `.DS_Store`, `.vscode/`
- the internal `.docx` notes

The current application lives on the `super` branch. Runtime music paths are
documented in `README.md`; the archive is source-only.
