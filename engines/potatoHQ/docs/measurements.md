# 测量方法与结果

所有数字都来自 `make run-tests`(`build/phq_tests`),原始输出存档在 `work/test-output.txt`。
测量全部在离线、双精度、无外部仪器条件下完成,**不代表真机 DAC 的模拟指标**。

## 1. 升频器(44.1 kHz → 705.6 kHz,K=128)

方法:生成 1 kHz 正弦,分块(1024 帧)流式过升频器,丢弃群延迟后做最小二乘正弦拟合。

| 指标 | 结果 |
|---|---|
| 1 kHz 幅度误差 | **−0.0012 dB** |
| 43.1 kHz 镜像(1 kHz 的镜像) | **−101.1 dB** |
| 20 Hz–20 kHz 最差通带偏差 | **0.0314 dB** |

镜像抑制由 Kaiser 窗阻带决定;−101 dB 与 128 taps/phase、120 dB 设计目标的预期一致(阻带边缘略低)。
通带在 19–20 kHz 处有约 0.03 dB 的滚降,因为 −6 dB 点设计在 Nyquist;把 `tapsPerPhase` 提到 192 可减小该滚降。

## 2. ΣΔ 调制器(DSD64 = 2.8224 MHz,20 Hz–20 kHz 带内)

方法:2 s 正弦(幅度 0.5,内部 −3 dB 余量)→ 调制 → 对 1-bit 流做 2¹⁹ 点 FFT(7 项 Blackman-Harris 窗,−180 dB 旁瓣),
统计 20 Hz–20 kHz 内除信号主瓣(±10 bin)外的噪声功率。

| 阶数 | NTF 峰值增益 | 带内 SNR | 稳定性 |
|---|---|---|---|
| 3 | 2.0 | **80.9 dB** | 0 次熔断 |
| 5 | 2.0 | **101.2 dB** | 0 次熔断 |
| 7 | 1.8 | **106.5 dB** | 0 次熔断 |

### 参数扫描(选型依据)

| 配置 | SNR | 熔断次数 |
|---|---|---|
| 5 阶 / 1.8 / −3 dB | 96.5 dB | 0 |
| 5 阶 / 2.0 / −3 dB | **101.4 dB** | 0 |
| 5 阶 / 2.2 / −3 dB | 崩(36 dB) | 1637 |
| 7 阶 / 1.5 / −3 dB | 90.0 dB | 0 |
| 7 阶 / 1.8 / −3 dB | **106.8 dB** | 0 |
| 7 阶 / 2.0 / −3 dB | 崩(38 dB) | 804 |

结论:7 阶 + 1.8 是这套 NTF 的甜点;再激进就进入极限环/失稳。更激进的噪声整形需要把 NTF 零点铺到带内
(Chebyshev/Butterworth 型),这是下一步工作。

### 两个测量陷阱(如实记录)

1. **窗旁瓣**:4 项 Blackman-Harris 旁瓣 −92 dB,会把 7 阶的测量值卡在 ~89 dB。换 7 项后同一信号测到 106.5 dB。
2. **抽取混叠**:测试里另有一条"时域 SNR"路径(2.8224 MHz → 44.1 kHz 单级抽取后减正弦),
   它稳定给出 ~81 dB,与 FFT 的 106 dB 矛盾。原因是单级抽取滤波器对**带外被整形放大的噪声**抑制不足,
   混叠回带内。这条路径属于**测量受限**,不是调制器指标;要得到可信时域结果需要 2–3 级级联抽取。
   真实播放路径不经过这条测量链。

## 3. 抖动(16-bit)

方法:零信号 → TPDF 抖动 → 量化 → 统计。

| 指标 | 结果 |
|---|---|
| 均值 | −3.1e−8 |
| RMS | **−96.32 dBFS**(≈0.5 LSB) |
| 是否落在整数格点 | 是(误差 < 1e−7) |

注意 −96.3 dBFS 是"抖动 + 量化"的合成 RMS;常说的 "TPDF ≈ −93 dBFS" 指的是峰峰值约 2 LSB 的口径,两者不矛盾。

## 4. DoP 与 DSF 结构

- DoP:构造已知字节模式,验证 `[later][earlier][marker]`(packed 24-bit)与 `[00][later][earlier][marker]`(24-in-32);
  marker 在**载波帧**级别 0x05/0xFA 交替(同帧多声道共用)。
- DSF:写 40000 bit,`ffprobe` 识别为 `dsd_lsbf_planar`;文件头、block(4096 B/ch)、sample count 均被正确解析。

## 4.1 DoP 载波(DSD64)

`potatohq dop` 生成 24-bit 载波 WAV,用 `tools/check_dop.py` 逐帧校验:

| 项 | 结果 |
|---|---|
| 载波率 / 位深 | 176400 Hz / 24-bit |
| 时长 | 10.000 s(1,764,000 帧) |
| marker 0x05 / 0xFA | 各 1,764,000,**0 错误** |
| payload 不同字节值 | 198(非恒定,说明是真实 1-bit 流) |

实时 DoP 的渲染逻辑另有两项单元测试:`dopCarrierWord()` 与离线 packer 逐字节一致;
Sigma-Delta 输出 → DoP 打包 → 反解回的 DSD 字节与调制器输出完全相同(`[dop-realtime]` / `[dop-sdm]`)。

## 4.2 Gapless

`tools/gapless_chain.py` 驱动 3 首 5 s 曲目(44.1k → 48k → 44.1k),在每次 `playback.track` 时自动 `setNext`:

| 项 | 结果 |
|---|---|
| 切换时刻 | 5.97 s / 11.01 s(与 5 s 曲长一致) |
| `playback.track` | 第 2、3 首带 `gapless:true` |
| **underruns** | **0** |
| 单曲结尾 | `finished:true`,position 钳在 duration,underruns 0 |

## 4.3 EQ 响度安全(重要)

Super 的 EQ preamp 是 **VLC 语义**:`12 dB == 单位增益`(VLC 内部有 0.25 干声系数)。
把 12 直接当 dB 用等于凭空 +12 dB,再叠加 band boost 就是"又响又炸"的根因。

现在的策略:适配层先换算 `p - 12.04 dB`,引擎再测 10 段级联峰值,把 preamp 压到峰值 ≤ 0 dBFS:

| 配置 | 输出幅度(输入 0.1) |
|---|---|
| 平坦(preamp 0) | 0.0998 |
| +20 dB band | **0.1001**(无 headroom 时会是 1.0) |
| preamp −6 dB | 0.0502 |
| +12 dB band + 预衰减 3 dB | 0.0998 |

mpv 侧同样换算,并追加 `alimiter=limit=0.95`;实测有效音量(基准 0.78):
平坦 0.776、+20 dB band **0.078**、−6 dB band 0.776、关闭 0.780。

## 4.3b EQ 实时切换

1 kHz / 0.1 幅度正弦,播放中把 EQ 从旁路切到 +6 dB @1 kHz:

| 项 | 结果 |
|---|---|
| 淡入期间最大相邻样本差 | **0.02604**(纯正弦导数为 0.02618 → 无台阶) |
| 淡出期间最大相邻样本差 | 0.01305(单位增益正弦导数) |
| +6 dB 稳定后幅度 | **0.1995**(理论 0.1995) |
| 关闭后幅度 | 回到 0.1000(±0.002) |

播放中通过 RPC 连续改两次 EQ:播放不中断,`underruns` 保持 0。

## 4.4 升频器阻带 vs taps(为什么不做半带级联)

单级 64× 升频器在带边附近的实测阻带(原型滤波器响应,截止 22.05 kHz):

| taps/phase | 22.1 kHz | 24.1 kHz | 25.1 kHz | 30 kHz |
|---|---|---|---|---|
| 24 | −6 dB | −16 dB | −24 dB | −123 dB |
| 32 | −6 dB | −21 dB | −34 dB | −126 dB |
| 48 | −6 dB | −34 dB | −68 dB | −130 dB |
| **64** | −6 dB | **−55 dB** | **−121 dB** | −130 dB |
| 96 | −7 dB | −122 dB | −132 dB | −135 dB |

结论:带边锐度只能靠**单级长滤波器**换来。2× 半带级联的每一级截止点都在自己速率的一半,
过渡带相对更宽,同样的 taps 下 24 kHz 处只有约 −20 dB;要在级联里达到 −120 dB,每级都要
156 taps/phase,总 MAC 反而更高。所以**没有采用级联**,而是优化了单级实现:

- 内层循环从"逐帧取模 + 边界分支"改成"线性历史 + 块处理":无 `%`、无分支、连续访存;
- 10 s 音频的生成耗时(44.1k 源,单线程):

| 目标 | 耗时 | 倍速 |
|---|---|---|
| 705.6 kHz / 24-bit | 0.70 s | 14× |
| DSD64 | 2.38 s | **4.2×** |
| DSD128 | 4.83 s | 2.1× |
| DSD256 | 10.29 s | ~1.0× |

## 4.5 DSD 路径端到端 SNR

44.1k 正弦 → 升频到 2.8224M → 7 阶 SDM(与真实播放路径一致),带内 SNR:

| taps | 带内 SNR | 43.1 kHz 镜像 |
|---|---|---|
| 32 | 107.1 dB | −94.5 dB |
| 48 | 106.4 dB | −98.7 dB |
| **64** | **106.9 dB** | **−95.0 dB** |
| 96 | 107.0 dB | −91.4 dB |

带内 SNR 由调制器决定,几乎与插值器无关;taps 影响的是**带外**(见 4.4),所以保持 64。

## 4.6 空间声场与频谱

| 项 | 结果 |
|---|---|
| 关闭时直通 | 逐样本完全相等(bit-exact bypass) |
| 硬右 (x=+1) | 左 0.0000,右 0.0636(= 单位 × 距离增益 0.45) |
| 中心 | 左右均 0.1413(输入 0.2 正弦的有效值 0.1414) |
| ITD (x=+0.5) | 右耳峰值 100,左耳 114 → **14 样本**(48 kHz 下 0.29 ms) |
| 后方 (y=−1) | 6 kHz/500 Hz 倾斜比前方低 **4.9 dB** |
| 拖动 0→+1 | 最大相邻样本跳变 0.0279(≈ 正弦自身导数) |
| 频谱 tap | 1 kHz 单音 → 事件 46 条/2.5 s,峰值落在 900–1026 Hz 频段 |
| 交叉馈电关闭/强度 0 | 逐样本完全相等 |
| 交叉馈电(硬左脉冲) | 右耳在 126 样本处出现 0.0139 的低通能量,左耳峰值 0.667(=(1/1.5)) |
| 交叉馈电(单声道) | 左右逐样本相等(对称) |
